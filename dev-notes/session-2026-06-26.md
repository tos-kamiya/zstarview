## Scope
Add inline comment support to `scripts/zstarview_export_image_schedule_runner.py`.
A `#` anywhere on a config line now strips the remainder of the line before parsing.

## Decision
- Topic: Inline comments in the schedule runner config file
    - Decision: Strip everything from the first `#` to end-of-line before shell-style tokenization.
    - Rationale: The previous parser only ignored full-line comments via `shlex.split(..., comments=True)`, which requires `#` to start a new word. The user requested that any `#` in the line begin a comment, so explicit pre-processing is clearer and matches the requirement exactly.
    - Alternatives Considered: Leaving comment handling to `shlex` only. Rejected because it does not treat `#` attached to a token as a comment (e.g. `run#comment`).
