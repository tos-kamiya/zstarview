# Session 2026-04-02

- Scope: Investigate current handling of building heights in the codebase.

- Topic: Urban outline building height baseline
  - Decision: Treat Overture building `height` as above-ground building height, then add DEM-derived ground elevation for both building and observer before computing apparent altitude.
  - Rationale: The current method ignores terrain elevation differences and biases apparent altitude, especially for distant buildings on higher or lower ground.
  - Alternatives Considered: Continue using raw `height_m` only. Rejected because it systematically underestimates elevated buildings and overestimates buildings on lower ground.

- Summary:
  - Updated `docs/design.md` to define DEM-based ground elevation as the reference surface for urban outline apparent altitude.
  - Updated `docs/implementation-history.md` to record the design decision and remaining implementation questions.
  - Implemented DEM-backed observer/building ground elevation sampling in the urban outline runtime path and switched apparent altitude calculation to absolute elevation difference.
  - Added `min_height` plumbing for Overture building parts and preserved the semantics that `height` remains ground-to-top while `min_height` only describes an elevated bottom.
