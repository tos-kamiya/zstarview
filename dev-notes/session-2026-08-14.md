- Topic: Scintillation display effect
  - Decision: Treat scintillation as a GUI-only visual approximation, not a physical atmosphere
    simulation. At the lightweight 2-second display update, choose a random direction within the
    current rendered field and select the nearest eligible visible star within 1 degree. Exclude
    stars rendered in the individual bright-star pass and all solar-system bodies. Overlay a
    dark, translucent dot approximately the rendered star size on the star surface before
    applying the existing star interpolation homography. Do not enable the effect in
    `zstarview-export-image` or Atlas.
    - Final initial parameters: enabled by default; base opacity 0.6 at altitude 10 degrees;
      dot-size multiplier 1.0; no same-star avoidance; no temporal interpolation, so each
      selected star shows the effect for one 2-second display interval.

- Topic: Scintillation implementation
  - Decision: Add pure NumPy-based candidate selection and altitude-strength helpers, keep the
    selected target in GUI state, and apply the dimming mask inside the cached faint-star raster
    before the existing star interpolation transform.
  - Rationale: This preserves the existing bright-star individual pass and keeps the temporary
    effect attached to the interpolated star surface. Atlas and export-image remain unaffected.
  - Validation: Added unit tests for altitude clamping, spherical nearest-neighbor selection,
    azimuth wrapping, and random view sampling. Full pytest and ruff validation passed.

- Topic: Scintillation visibility tuning
  - Decision: Increase the nearest-star search radius from 1 degree to 3 degrees and base the
    dimming-dot diameter on the rendered star size after the minimum 1-pixel clamp.
  - Rationale: The original event probability was too low in typical fields, and sub-pixel
    source sizes could produce a mask that missed the only rendered pixel.

- Topic: Scintillation event count
  - Decision: Select up to 10 distinct eligible stars on each 2-second update and render all
    selected dimming dots simultaneously.
  - Rationale: A single random target remained too difficult to notice during ordinary viewing.

- Topic: Scintillation base opacity tuning
  - Decision: Increase the altitude-10-degree base opacity from 0.2 to 0.6.
  - Rationale: The dimming effect remained difficult to perceive in normal viewing.

- Topic: Scintillation altitude exponent
  - Decision: Change the altitude strength exponent from 1.5 to 1.0.
  - Rationale: The 1.5 exponent made high-altitude scintillation nearly invisible; exponent
    1.0 keeps the low-altitude emphasis while making the effect observable higher in the sky.

- Topic: Scintillation direction sampling
  - Decision: Remove the temporary azimuth concentration around the viewing direction and
    sample the full circular view field using uniform spherical-cap area.
  - Rationale: The azimuth restriction was only a visual diagnostic aid; normal behavior should
    allow events throughout the observed field with direction probability proportional to sky
    area.

- Topic: Scintillation visibility experiment
  - Decision: Temporarily increase the per-update scintillation target count from 10 to 100.
  - Rationale: Make the aggregate visual strength easier to evaluate during manual observation.
