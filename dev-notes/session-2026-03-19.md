# Session 2026-03-19

- Scope: 雲データ取得・描画の水平線近傍カットオフを 2.5 度から 3.0 度へ調整

- Topic: 雲オーバーレイの可視下限の引き上げ
  - Decision: `SkyWindow` が `CloudDiscConfig` に渡す既定の `alt_min_deg` を `3.0` に変更した。
  - Rationale: 水平線直上の遠距離雲を既定表示から少し強めに除外し、観測補助としての見通しを優先するため。
  - Alternatives Considered: `CloudDiscConfig` 自体の dataclass 既定値を変える案もあるが、アプリの既定挙動変更という今回の要求に対しては UI 初期化地点の設定値だけを変える方が影響範囲を限定できる。

- Summary:
  - Changed the app default cloud horizon cutoff from `2.5` to `3.0` degrees.
  - Added a focused regression assertion for the default cutoff value.
  - Updated specification, design, and implementation-history docs to match.
  - User-reported failures in `tests/test_cli_mountain_options.py` and `tests/test_cli_tower_options.py` appear unrelated to this cloud cutoff change and were not modified in this task.

- Topic: dataset query CLI validation drift
  - Decision: `parse_args()` の dataset query 互換性チェックは、固定数値ではなく `parser.get_default()` を参照するように変更した。
  - Rationale: CLI オプションの既定値が更新された後も validation 側だけが古い値のまま残るのを防ぎ、`--list-viewpoints` / `--show-viewpoint-json` が既定状態で誤って失敗する回帰を避けるため。
  - Alternatives Considered: 比較式の数値だけを現状値へ更新する案もあるが、今後また同じドリフトが起きるため採らなかった。

- Topic: 航空機予想折れ線の表示区間延長
  - Decision: OpenSky の取得周期と予想再投影周期は維持したまま、航空機の予想折れ線を `2秒前 -> 現在 -> 2秒後` から `4秒前 -> 現在 -> 4秒後` へ変更した。
  - Rationale: 無料枠の `5分` 取得では表示更新の密度が低く見えやすいため、予想進行方向の線分を少し長くして視認性を上げる方が UI 上の効果が大きい。取得頻度や再投影タイマーを変えないので、API 利用量や更新負荷は据え置ける。
  - Alternatives Considered: 再投影周期自体を短くする案もあるが、今回の要求は見た目の密度改善であり、線分延長の方が局所的で副作用が小さい。

- Topic: 航空機予想線の折れ角緩和
  - Decision: 航空機予想線は `始点-現在-終点` の 3 点ではなく、`-4, -2, 0, +2, +4秒` の 5 点を投影したポリラインで描画するよう変更した。
  - Rationale: 近距離機体では `alt/az` 投影の非線形性により 3 点折れ線の中央折れ角が大きく見えるため、投影後の中間点を追加して見た目の曲率を滑らかにする方が自然だった。画面上のベジェ補間よりも、既存の物理予測と投影経路をそのまま使える点が堅い。
  - Alternatives Considered: `QPainterPath` によるベジェ曲線化も可能だが、画面座標上の見た目補間に留まり、広角表示や視野端での自然さを保証しづらいため採らなかった。
