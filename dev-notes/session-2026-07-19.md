Scope: Investigate publicly available road datasets for zstarview.

- Topic: Road-data source survey
  - Decision: No implementation change in this session; compare OSM/Overture with Japanese GSI and PLATEAU sources before choosing a runtime source.
  - Rationale: The best source depends on whether zstarview needs a lightweight visual road layer, authoritative Japanese geometry, or 3D road structure.

## End summary

- Recommendation: start with Overture Transportation road segments for a cached centerline overlay; retain GSI Fundamental Geospatial Data as a Japan-specific precision option.
- No source-code or public documentation behavior was changed.
- Confirmed that Overture Transportation `segment` has optional `width_rules`, measured edge-to-edge in meters and optionally varying by normalized position along the segment.
- Updated `docs/specification.md` and `docs/design.md` to define a 50m road-proximity overlay that renders only segments with explicit `width_rules`; no-width data has no fallback rendering.
- Documented that the road overlay is omitted during fast-mode/simplified display, including acquisition and projection work.
- Added `dev-samples/overture_transportation_probe.py` and documented it in `dev-samples/README.md`.
- Probe result for Tokyo Station (`35.681236, 139.767125`, 50m bbox): download succeeded with 156 features and 108 road segments, but 0 road segments contained `width_rules`.
- Size probe at the same location: 50m GeoJSON output was 789,439 bytes; a 100m bbox produced 314 features, 266 road segments, and a 1,005,166-byte GeoJSON output. Both runs had zero `width_rules` road segments.
- Interpretation: output volume is modest for this small-area probe; remote download latency is more noticeable than local feature volume. The 100m bbox is a reasonable first retrieval margin around the 50m drawing radius, subject to wider geographic sampling.
- Follow-up: sample multiple cities and road classes before deciding whether explicit-width rendering is viable.
- Moved the unimplemented road specification and design proposal out of the current documents into `docs/specification-road-overlay-not-implemented.md` and `docs/design-road-overlay-not-implemented.md`; the current specification and design no longer describe an active road feature.
