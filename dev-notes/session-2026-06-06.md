# Session 2026-06-06

Scope: investigate and fix `--window-frame window` startup failure.

- Topic: Standard window startup crash
  - Decision: Add a shared `Help` menu in `_build_window_menu()` so `StandardSkyWindow._install_window_host()` can add `self.help_menu` safely.
  - Rationale: `--window-frame window` was failing during startup because `help_menu` was never created before being attached to the menu bar. Making it part of the shared menu setup keeps frameless and decorated hosts aligned.
  - Validation: `uv run -p .venv/bin/python pytest tests/terrain/test_terrain_horizon_ui.py -q -k build_window_menu`
  - Validation: `uv run -p .venv/bin/python pytest tests/test_window_help_menu.py -q`

- Topic: User-initiated shutdown logging
  - Decision: Emit a single `INFO` log from `_begin_shutdown()` when shutdown is requested.
  - Rationale: The menu `Exit`, the window close button, and the frameless hamburger menu `Exit` action all funnel through the same shutdown path. Logging there distinguishes intentional shutdown from crashes without duplicating messages.
  - Validation: Added a regression test in `tests/test_window_shutdown_message.py`.
