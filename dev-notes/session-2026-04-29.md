  - Notes: Distance-band widths decrease with band distance, and every band uses the same horizon color so only thickness changes across layers.

## 2026-04-29

- Topic: Copernicus DEM download resilience
  - Decision: Invalid downloaded DEM tiles are now skipped instead of aborting the entire fetch. If no valid tiles remain, the existing "No Copernicus DEM tiles were downloaded for the requested area." path is used.
  - Rationale: The previous behavior turned a single bad S3 object into a hard failure during urban-outline updates. Skipping the bad tile keeps the rest of the area working and preserves the existing caller fallback when nothing usable is available.
  - Alternatives Considered: Raising a more specific error for invalid tiles was rejected because the caller already has a stable fallback for the "no tiles" case.
