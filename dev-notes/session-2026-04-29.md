- Topic: Terrain horizon auxiliary ridge layer
  - Decision: Keep the existing terrain horizon polyline as the primary silhouette, and add a separate auxiliary ridge layer for secondary peaks when needed.
  - Rationale: The current horizon path is a single maximum-altitude envelope per azimuth, which preserves a clean silhouette. A second layer can expose mountain ridges without destabilizing the main horizon rendering or changing existing semantics.
  - Notes: The auxiliary layer should be optional, low-opacity, and thresholded so that DEM noise does not turn the view into a dense jagged trace.

- Topic: Distance-band ridge visualization
  - Decision: Replace the previous secondary peak chaining with concentric distance-band ridge lines for the first visual experiment.
  - Rationale: The banded view is easier to reason about than chained secondary peaks, and it better exposes how nearby terrain blocks or reveals farther ridges. The initial pass keeps every band the same thickness and renders them in red so the shape, not the styling, is the focus.
  - Notes: The first cut uses distance bands at 3.75, 7.5, 15, 30, 60, and 120 km, with the primary silhouette unchanged.
