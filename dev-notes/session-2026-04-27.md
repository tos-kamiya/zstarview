# Session 2026-04-27

- Scope: Review the proposed Earth guide fill/clipping approach without changing implementation.
- Topic: Earth guide fill/clip proposal
  - Decision: The proposal is directionally reasonable as a coarse near-observer exclusion heuristic, but it is not sufficient by itself as a fill strategy and is likely to reintroduce topology problems unless the final clipping/fill happens after projection or via a raster/mask stage.
  - Rationale: The current implementation already uses observer-distance dead zone plus altitude clipping, so a surface-distance circle is mostly a refinement of an existing coarse filter. The main failure mode is polygon topology near the observer and the horizon, which a pre-projection circle does not remove.
- Topic: Earth guide point-cloud fill direction
  - Decision: Reframe fill as point-cloud hatching instead of strict polygon fill. Prefer an approximately equal-area sampler as the baseline, then compare a few visually distinct variants with the same clip rules.
  - Rationale: Point clouds remove the polygon topology failure mode and make observer-distance clipping trivial. Equal-area sampling gives a more uniform visual density across latitude, which matters for a globe view.
- Summary:
  - Implemented point-cloud fill for Earth guide with cached per-ring sample points and a 600 km near-observer clip for the fill path.
  - Added equal-area sampler as the baseline, with alternate `latlon` and `jitter` modes kept in the helper for future comparison.
  - Verified with `pytest tests/test_earth_guide_render.py` and `ruff check src/zstarview/render/earth_guide.py tests/test_earth_guide_render.py`.
  - Increased fill visibility after the first pass was too subtle in practice by raising point density, point radius, and fill alpha, and by enabling antialiasing for the fill layer.
  - Antarctica-like rings are excluded from fill-point generation because the pole-spanning topology is too brittle for the point-cloud approximation; outline rendering stays unchanged.
  - Switched the fill layer from isolated dots to short line segments between adjacent points within the same latitude band so it reads less like stellar points.
