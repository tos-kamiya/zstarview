# B13/B16による雲シェル配分の改善方針

作成日: 2026-08-27
種別: 実装方針 handoff

## 背景

現在の通常の雲経路は、Himawari の B13（M1C13）または GOES の C13
から輝度温度（BT）を取得し、雲の強度を描画用の 0..1 値へ変換している。
現在の変換は気象学的な雲量・雲頂高度の直接 retrieval ではなく、雲頂が
冷たいほど雲らしいという関係を利用した表示用ヒューリスティックである。

```text
amount = clip((BT_warm - BT13) / (BT_warm - BT_cold), 0, 1)
```

`BT_warm` と `BT_cold` は既存のローカル／赤道帯サンプルから推定し、低い
amount は既存の抑制処理で除去する。

現在の 3 km、5 km、7 km の雲シェル配分も、シーン全体の雲量から決める
簡易的な重みであり、セルごとの雲の高さを観測しているものではない。

## 採用方針

B13 と B16 を同じ観測時刻・同じ地理座標で取得し、B13 の雲量に加えて
B13/B16 の差から「高層雲らしさ」を推定する。高層雲らしさを使って、
セル単位の 3/5/7 km シェル重みを滑らかに補正する。

```text
delta_bt = BT13 - BT16
high_score = calibrated_normalized(delta_bt)
```

2026-08-27 の診断結果を受け、描画用入力では差分を
`clip(delta_bt, 0 K, 30 K)` とする方針を採用した。クリップ前の値は診断用に
保持する。差分が小さいほど上層雲らしさが高い向きとするが、具体的なスコア
曲線は追加サンプルによる較正後に決める。

`delta_bt` の閾値、符号、スケールは最初から物理定数として固定せず、
実データと気象庁等の雲頂情報との比較で検証・調整する。B16 は CO2 吸収帯、
B13 は雲画像・雲頂情報に適した赤外線窓であり、両者の差は雲頂高度の手がかり
になる。ただし、差分だけで正確な高度を復元する処理とはしない。

## 想定する処理フロー

1. B13 と B16 を同時刻のデータとして取得し、各バンドを同じ観測者中心の
   alt/az グリッドへ投影する。
2. 既存の B13 処理で、各セルの基本雲量 `amount13` を作る。
3. B13/B16 の有効画素、欠損、極端な値を検査し、`delta_bt` を計算する。
4. `delta_bt` を 0..1 の `high_score` へ変換する。雲量がほとんどない
   セルでは `high_score` をシェル配分に使わない。
5. `amount13` と `high_score` から、3 km、5 km、7 km の重みを補間する。
   急な境界が出ないよう smoothstep 等で連続化する。
6. 既存のシェル別量子化、描画、雲欠損マスク、キャッシュキーへ必要な
   入力差分を反映する。

配分の初期値は、既存の配分を壊さないよう保守的にする。例えば高層雲らしさ
が高いセルで 7 km 側を増やすが、B16 が欠損・不安定なセルは従来の B13
ベース配分へフォールバックする。B16補正は従来配分と候補配分の混合率を
最大 `0.30` とする。シェル間の移動量に独立した絶対上限は設けず、移動元の
シェルに存在する量を超えない自然な制約だけを適用する。総雲量を保存し、主に
5 kmと隣接シェル間で移動させ、3 kmから7 kmへの直接移動は行わない。具体的な
候補重みとスコア曲線は診断結果から決める。

## 重要な制約

- B13/B16 は主に見えている雲頂を捉えるため、同一画素に重なる下層雲まで
  分離できるとは限らない。
- 正確な雲頂高度には、大気の気温・水蒸気プロファイル、放射伝達計算、
  雲の光学的厚さなどが必要になる。
- `3/5/7 km` は表示シェルであって、取得した正確な雲底・雲頂高度を意味
  しない。新方式もまずは「高い雲が多そうか」の表示近似として扱う。
- B11 は雲相判別、B16 は雲頂高度の手がかりという別の役割があるため、
  将来 B11 を追加する場合も、高さ推定と氷／水判定を別スコアとして扱う。
- B13 と B16 の取得量が増えるため、ネットワーク、キャッシュ容量、取得
  失敗時のフォールバックを考慮する。

## 実装候補

主な変更候補は以下のとおり。

- `src/zstarview/clouddisc/providers/`: B16 の取得とバンド別 source metadata
- `src/zstarview/clouddisc/sampling/`: B13/B16 の整列、差分、スコア化
- `src/zstarview/clouddisc/altaz_grid.py`: セル単位のシェル重み生成
- `src/zstarview/clouddisc/types.py`: 複数バンド source、品質フラグ、キャッシュ識別
- `tests/clouddisc/` および `tests/test_clouddisc_altaz_grid.py`: 差分の符号、
  欠損時フォールバック、重みの連続性、従来経路との互換性

まずは B16 を追加した診断用の差分画像・ヒストグラムを出し、気象庁の雲頂
高度情報や B13 画像と目視比較してから、描画シェル配分へ接続するのが安全である。
