- Topic: Diagnose OSM road-data failure in scheduled export
  - Decision: Interpret the reported `HTTP 504` as an Overpass API request
    failure, not an empty road dataset.
  - Rationale: `fetch_road_night_lights()` converts `urllib.error.HTTPError`
    into `RuntimeError("HTTP {code}")`. An empty successful Overpass payload
    (`elements: []`) is accepted by `parse_road_night_lights_payload()` and
    produces an empty snapshot; it does not enter the export layer failure
    path. The cache lookup also preceded the request, so this run had no valid
    scope cache for the requested location/radius.
  - Validation: Reviewed `src/zstarview/road_night_lights.py` and
    `src/zstarview/cli/export_image.py` against the supplied log.

  - Decision: Retry the default 10 km request once at 5 km when the request

  - Rationale: A smaller geometry response can succeed when the 10 km query
    is rejected by Overpass, while limiting the retry to one smaller radius
    avoids repeated load and preserves the existing failure behavior when the
    fallback also fails.
