# Session 2026-06-29

## Scope
- Make the cloud halftone hatch spacing follow the same base-plus-upscale rule as the star layer, while keeping the 600x600 default unchanged.

## Decision Log
- Topic: Halftone hatch spacing scaling
  - Decision: Changed `_halftone_grid_delta()` so the spacing stays identical at a 600 px reference diameter, scales directly below that size, and grows sublinearly above it using the same square-root style enlargement rule used by star rendering.
  - Rationale: This keeps the default 600x600 appearance stable while preventing large windows from making the halftone grid feel too sparse or too tightly proportional to the raw window size.
  - Alternatives Considered: Leaving the current linear spacing rule in place. That would preserve the existing behavior, but it would not match the star-layer scaling model the user requested.
