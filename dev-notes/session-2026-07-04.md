  - Decision: Changed the halftone grid spacing to scale proportionally with window diameter instead of growing via a square-root curve.

  - Notes: Updated the corresponding spacing expectation in the halftone sizing test.

  - Notes: Kept the change local to the diameter base constant so it remains easy to revert.
