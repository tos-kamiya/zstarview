# Session 2026-03-16

- Scope: Investigate why urban outline strokes appear thicker/darker in `shot1.png` (Tokyo) than `shot2.png` (Downtown Dubai).

- Topic: Tokyo vs Dubai urban outline thickness
  - Decision: Treat the visible difference as a data-loading and accumulation issue, not a per-stroke styling difference.
  - Rationale: `draw_urban_outlines()` uses the same pen widths for both locations (`1.5px` cosmetic, or `4px` only for narrow-span simplification) and higher buildings only scale alpha modestly. The larger effect comes from `_build_dynamic_urban_outline_layer()` aggregating buildings from every cached `*/bldg` directory whose tile envelope intersects the requested radius. Around Tokyo this machine currently has 14 overlapping cached Overture-derived directories; around Downtown Dubai it has 2. The resulting rendered outline counts were ~16,354 for Tokyo vs ~1,976 for Dubai, which makes Tokyo appear much thicker/darker through repeated overlapping strokes.
  - Alternatives Considered: Pure cloud-stripe explanation was rejected because sky/cloud layers are drawn before `_draw_urban_outline_layer()`, so the diagonal cloud hatch in the Tokyo screenshot is a separate visual factor but not the direct source of the urban outline stroke thickness.
