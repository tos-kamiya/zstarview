Scope: restore solar-system body rendering during viewport fast mode.

- Topic: Fast-mode solar-system rendering
  - Decision: Draw the existing solar-system layer during viewport interaction fast mode instead of limiting that path to stars and terrain only.
  - Rationale: The fast-mode path currently returns before the normal planet layer runs, which suppresses the Sun, Moon, and planets while panning or zooming. Reusing the existing solar-system renderer keeps the behavior aligned with normal rendering and confines the change to the interaction pipeline.
  - Alternatives Considered: Reimplement a dedicated fast-mode planet marker path. Rejected because it would duplicate body rendering logic and increase divergence between normal and fast paths.
