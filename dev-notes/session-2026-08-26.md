# Session 2026-08-26

Scope: Compare Sandwich Harbour reference imagery with zstarview output and tune sky/sea color rendering.

- Topic: Default sky opacity
  - Decision: Raise the default `-S/--sky-opacity` from `0.16` to `0.25`
    across CLI parsing, GUI input defaults, documentation, and regression tests.
  - Rationale: Make the calibrated blue sky more readable without changing
    explicitly supplied `-S` values.

- Topic: Daytime sky colour balance
  - Decision: Reduce the intensity-to-luminance blend from 0.30 to 0.18 and
    set `SUN_RADIANCE_RGB` to `[0.45, 0.625, 1.0]`, midway between the
    previous moderate and strong corrections. Keep the standard
    Rec. 709 luminance weights unchanged.
  - Rationale: The supplied zstarview image at `-S0.5` measured approximately
    RGB (59, 86, 118) in the upper sky, while the reference was approximately
    (3, 49, 111). The simpler change weakens the white-making correction at
    high `-S` values, while the sunlight adjustment reduces the red/green
    cast in the scattered sky radiance itself to approach shot2.
