# Session 2026-03-15

- Scope: Update package metadata after the 1.0 release by changing the PyPI development status classifier from beta to production/stable.

- Topic: PyPI development status after version 1.0
  - Decision: Change the `pyproject.toml` classifier from `Development Status :: 4 - Beta` to `Development Status :: 5 - Production/Stable`.
  - Rationale: The package has reached major version 1, so the published metadata should match the intended release maturity shown on PyPI and other package indexes.

- Topic: README platform support note for Windows Arm64
  - Decision: Add installation notes to `README.md`, `README_ja-JP.md`, and `README_pypi.md` stating that Windows Arm64 is currently unsupported, and mention the observed `shapely` build failure as the reason.
  - Rationale: A real installation attempt on 2026-03-15 failed on Windows Arm64 during native dependency build, so users should see that limitation before trying `pipx install`, including on the PyPI project page.

- Topic: Suppress planet labels when the body marker is off-screen
  - Decision: Only enqueue planet and moon labels when the rendered marker still intersects the current `QPainter` viewport, instead of relying only on the spherical field-of-view check.
  - Rationale: In very wide, low-altitude views, a body can remain inside the 90-degree FOV while its projected marker falls completely outside the actual window. Matching label visibility to marker visibility removes orphaned labels such as off-screen Jupiter/Uranus in low-horizon views.

- Summary:
  - Updated the package classifier in `pyproject.toml`.
  - Added Windows Arm64 installation limitation notes to the English, Japanese, and PyPI READMEs.
  - Suppressed solar-system labels when the body marker is fully outside the window viewport.
  - Added a render test covering the off-screen planet-label case.
