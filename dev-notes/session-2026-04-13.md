  - Decision: Use `cache_meta.json` sidecars for dataset-level metadata and `overture_buildings_release_check_meta.json` at the cache root for release lookup state.

  - Decision: If release metadata is missing or unreadable, keep the cache and fall back to TTL-based stale handling instead of deleting data.
