Scope: evaluate temporal suppression for Geo-satellite color-image cloud proxies using 3 local PNG frames.

- Topic: Temporal overlay suppression for Geo-satellite proxy
  - Decision: Add a separate `dev-samples` script that combines 3 frames, estimates static overlays from RGB consistency, and dampens those regions before producing the grayscale proxy.
  - Rationale: Persistent map overlays such as coastlines and borders are much easier to identify by temporal stability than by color alone. Keeping this outside `zstarview` preserves the exploratory workflow and avoids coupling the heuristic to the main app.
  - Alternatives Considered: Editing the earlier single-frame proxy script in place. Rejected because the single-frame workflow is still useful for quick experiments and should remain simple.

- Topic: Static RGB mask extraction
  - Decision: Replace the exact-RGB mask with a local-background subtraction pass that keeps bright, line-like pixels that remain stable across all 3 frames.
  - Rationale: The boundary lines are not fixed-color overlays; they appear to be additive or blended into the source image. A local contrast residual is therefore a better detector than raw RGB equality.
  - Alternatives Considered: Keeping the exact-RGB mask or only the cloud-likelihood proxy. Rejected because both missed the line-art structure the user observed.
