# Session 2026-06-09

Scope: Document and implement a unified User-Agent policy for outbound API requests.

- Topic: Unified User-Agent for external API access
  - Decision: Define a single application-wide base User-Agent for outbound requests, then append a service-specific suffix where needed.
  - Rationale: This keeps requests identifiable as zstarview traffic while still preserving enough context for service operators and future debugging.
  - Alternatives Considered: A single literal User-Agent across every service, but that reduces per-service traceability and makes diagnostics less explicit.
