# Session 2026-09-04

Scope: Continue the application-owned services refactor started on 2026-09-03.

- Topic: Core GUI ApplicationServices boundary
  - Decision: Let `SkyWindow` own one `ApplicationServices` instance and inject
    it into sky, cloud, and Geo-satellite background components.
  - Rationale: These components share an executor, a native-work serialization
    lock, and a lazy ephemeris provider. Explicit ownership makes their lifetime
    and shutdown order visible without splitting resources that must remain
    shared.
  - Alternatives Considered: Auxiliary controllers and startup/search dialogs
    remain on the compatibility worker pool for this incremental change. The
    window shuts down both service-owned and compatibility pools until that
    migration is complete.

- Validation: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q`
  completed with 1660 passed and two existing cloud-grid cast warnings. Changed-
  file Ruff checks, compileall, and `git diff --check` also passed.

- Topic: Export CLI ephemeris lifetime
  - Decision: Keep the process-global ephemeris cache for
    `zstarview-export-image`.
  - Rationale: The export command is a one-shot process, so the cache lifetime
    already matches the command lifetime and avoids loading the ephemeris twice
    during startup verification and rendering. The GUI no longer relies on this
    global for its service-owned work.
  - Alternatives Considered: Inject a CLI-owned `EphemerisProvider` through the
    export pipeline. This would make ownership explicit but adds plumbing without
    a practical lifetime or cleanup benefit for the one-shot command.
