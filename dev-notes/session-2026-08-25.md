# Session 2026-08-25

Scope: sky discの高opacity時の彩度と、ブルーアワーの青色残光の調整。

## Design decisions

- Topic: 高いsky intensityにおける輝度と色差の配分
  - Decision: 最大輝度混合率を`0.65`から試験的に`0.55`へ下げた後、最終的に
    `0.30`とする。混合カーブ`d = 0.30 * p^1.5`とRec. 709輝度係数は維持する。
  - Rationale: 高い設定で空色が過度に高彩度になることを抑えつつ、55%以上の混合で
    薄明の青色差まで失われる問題を軽減する。
- Topic: 薄明多重散乱によるブルーアワーの近似
  - Decision: 実効RGBを`[0.008, 0.020, 0.070]`から
    `[0.032, 0.080, 0.280]`へ4倍化する。太陽高度と視線高度の既存カーブは変更しない。
  - Rationale: 日の出前の実写画像と比較すると、従来値では高空の青色残光が不足した。
    RGB比、強度、輝度混合率を段階的に比較し、RGB比を変えずに不足分を補った。
- Topic: 散乱後の経験的RGBバランス
  - Decision: `[0.98, 1.00, 1.00]`の乗算を廃止し、未使用定数も削除する。
  - Rationale: 代表波長、消散、オゾン、薄明近似、表示変換とは別の色調整を減らし、
    各成分の効果を追跡しやすくする。
