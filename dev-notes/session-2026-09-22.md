# Session 2026-09-22

Scope: Review NumPy/Numba star rendering and test premultiplied QImage output.

- Topic: Version bump
  - Decision: Increase the application version from `1.58.1` to `1.59.0` and
    add the matching release-notes entry.
  - Rationale: The requested `+0.1` bump applies to the minor component and
    resets the patch component to zero.

- Topic: Star image format experiment
  - Decision: Do not use `Format_ARGB32_Premultiplied` for the current star
    renderer. Keep the original NumPy + `Format_RGBA8888` + QImage/QPainter
    path.
  - Rationale: The premultiplied implementation showed a visible Mach-band
    artifact in subtle dawn-sky gradients. The measured speed improvement did
    not justify accepting a visual regression in the production renderer.

- Topic: Numba star rasterizer experiment
  - Decision: Keep the Numba rasterizer as an experiment only; do not add it to
    the production star-rendering path yet.
  - Rationale: The prototype accelerated the isolated regular-rectangle stage,
    but the full rendering path remained dominated by image conversion and Qt
    composition. The production path should remain the existing NumPy version
    until all visual modes have a pixel-level comparison.

- Topic: Reverting the production change
  - Decision: Revert commit `c6754e51` with commit `26b94d63` and preserve the
    original rendering behavior.
  - Rationale: Reverting is safer than rewriting branch history and leaves the
    cause and resolution visible in Git history.

- Session summary
  - Production star rendering is back to NumPy + RGBA8888 + QImage/QPainter.
  - The premultiplied-format experiment and Numba prototype are not active in
    production.
  - Version metadata was updated to `1.59.0` and committed.
