# Session 2026-08-11

Scope: Prevent the image schedule runner from catching up stale tasks after
the host resumes from sleep.

- Topic: Handling overdue scheduled image exports
  - Decision: Discard each occurrence that is at least three minutes late and
    log a warning containing its task, scheduled time, and delay.
  - Rationale: Laptop sleep and long-running commands can both leave stale
    occurrences in the queue. Applying one deadline at dispatch time prevents
    burst generation regardless of why an occurrence became overdue.
  - Alternatives Considered: Detecting only system resume would miss delays
    caused by serialized commands and would add platform-specific complexity.

## Summary

- Added a three-minute dispatch deadline and warning for discarded tasks.
- Added boundary and warning-message tests.
- Follow-up: None.
