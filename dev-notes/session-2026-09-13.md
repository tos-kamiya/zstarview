- Scope: Rename the Space-cycled visible-only display mode.
  - Decision: Use `Landscape view` as the user-facing name and rename the
    internal mode and helper/field names to `landscape` / `landscape_mode`.
  - Rationale: The mode emphasizes terrain, water, buildings, and the Earth
    guide, while `visible objects only` describes its implementation rather
    than the user's viewing intent. Keep the rendering behavior unchanged.

    overlay pipeline as the current behavior, update stale layer-order
    expectations, and make export-image meteor options optional for callers
    that still construct legacy option namespaces.
  - Rationale: The failing tests predated the latest display-mode and render
    pipeline changes. The export fallback preserves compatibility without
    changing parsed production options; missing meteor settings remain
    disabled.
