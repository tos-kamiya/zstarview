# Development session 2026-09-13

- Scope: Rename the Space-cycled visible-only display mode.
  - Decision: Use `Landscape view` as the user-facing name and rename the
    internal mode and helper/field names to `landscape` / `landscape_mode`.
  - Rationale: The mode emphasizes terrain, water, buildings, and the Earth
    guide, while `visible objects only` describes its implementation rather
    than the user's viewing intent. Keep the rendering behavior unchanged.

- Summary: Renamed the mode constant, state field, helper methods, render
  parameters, tests, README entries, specification, and release notes.
  No backward-compatible aliases were retained.
