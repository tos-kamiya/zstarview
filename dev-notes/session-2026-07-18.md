- Topic: Handle an empty PLATEAU batch preflight as a CLI error
  - Decision: Catch only the `ValueError` raised by the batch preflight in
    `main()`, print it with an `Error:` prefix to stderr, and return status 1.
  - Rationale: This removes the internal traceback from normal CLI output while
    preserving propagation of network and unexpected errors.
