# Session 2026-07-02

Scope: clarify how zstarview changes the visible sky region when the client-area aspect ratio changes.

- Topic: Document client-area aspect ratio behavior
  - Decision: Added a new specification section stating that `edge_fov_deg` is the projection baseline, `content_fov_deg` is overscan only, and the client-area aspect ratio can change how the sky disc is clipped and positioned.
  - Rationale: The behavior was implemented but not explicitly documented. Making the `edge_fov_deg` vs `content_fov_deg` split and the wide/tall layout rule explicit reduces ambiguity for users and future maintenance.
