# Session 2026-11-23

Scope: README reorganization around the "standing on a glass Earth" framing.

- Topic: README introduction and length
  - Decision: Open README.md with "You are standing on an Earth made of
    glass." followed by a short description of what is above, around, and
    below the observer. The word "glass globe" itself is not used. Keep the
    existing Features / overlay-group descriptions as they are.
  - Decision: Move the "Screen descriptions" section and "Other screenshots"
    table out of README.md into the new `docs/gallery.md` (image files are
    unchanged), and link to it and to the timelapse from one line under the
    hero image.
  - Decision: Use `docs/images/shot5.png` (a copy of the root `shot5.png`) as
    a placeholder hero image; it will be replaced later.
  - Rationale: The README had grown long, mostly because of the per-feature
    screenshots from older versions. The glass-Earth framing explains in one
    sentence why stars below the horizon and the far side of the Earth are
    visible through the ground.
  - Alternatives Considered: Adding glass-like transmission tint or refraction
    to the rendering was rejected; the framing is explanatory only. A new
    distance-ordered layer model in the README was also rejected because the
    existing overlay-group descriptions already cover it.
  - Follow-up: README_ja-JP.md and README_pypi.md still have the old
    structure; update them after the English README is settled. Replace the
    placeholder hero image.

- Topic: Japanese README
  - Decision: Apply the same structure to README_ja-JP.md ("あなたはガラスで
    できた地球の上に立っています。" intro, shot5 placeholder, timelapse and
    gallery links). Move its screenshot section to `docs/gallery-ja_JP.md`,
    following the `*-ja_JP.md` naming used by `docs/cli-*`.
  - Decision: Fix the stale Python 3.10 badge and test-matrix line in
    README_ja-JP.md to 3.11-3.14, matching `requires-python = ">=3.11"`.
  - Follow-up: README_pypi.md still has the old structure.

- Topic: README_pypi.md
  - Decision: Rewrite README_pypi.md for readers who only see PyPI: the same
    glass-Earth intro and placeholder image (absolute raw.githubusercontent
    URL on `main`), then installation as the main body (pipx, overturemaps,
    first run, optional data), a short usage section, a three-line summary of
    what is shown, troubleshooting pointers, and links. Drop the per-feature
    screenshot section and the detailed highlights list; link to the GitHub
    README instead.
  - Rationale: PyPI visitors need to get the app running; feature details
    and screenshots live on the project page and drift out of date when
    duplicated.
  - Note: The hero image URL points at `main`, so it shows on PyPI only
    after this change is merged to `main` before the next release.
  - Decision: Remove the timelapse link from README.md, README_ja-JP.md, and
    README_pypi.md. Keep the gallery links in README.md and README_ja-JP.md;
    gallery images are being collected separately.
