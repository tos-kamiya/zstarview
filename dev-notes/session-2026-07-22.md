- Topic: Night-light altitude at elevated observation sites
  - Decision: Require the night-light profile API to receive `observer_elevation_m` as an absolute elevation, and pass ground elevation plus observer/location height from both the GUI and image-export paths.
  - Rationale: The GUI and export callers previously omitted the elevation argument, so terrain samples near 3000m were projected from 0m above sea level. At azimuth 330 degrees for `@40.031250,-106.060960`, this placed the alpha peak at 22 degrees while the terrain horizon was 0.689 degrees. Passing 2887.02m moves the peak to 0 degrees and restores strong contact with the ridge.
  - Alternatives Considered: Keeping the ambiguous `observer_height_m` parameter and fixing only the GUI caller was rejected because export had the same defect and the default value of 0m could silently reintroduce it.
