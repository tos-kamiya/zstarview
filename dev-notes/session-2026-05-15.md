# Session 2026-05-15

- Scope: README note for Overpass water-surface download volume and cache behavior.

- Topic: README water-overlay usage note
  - Decision: Document that coastal or elevated viewpoints can cause a single Overpass fetch to return multi-megabyte water-overlay data, that the raw footprint is cached per viewpoint, and that frequent viewpoint changes can accumulate download volume toward the public Overpass instance's rough 1 GB/day safety guideline.
  - Rationale: The water overlay is the one runtime feature most likely to expose users to Overpass's fairness controls. The README should warn about the practical download cost without describing the public-instance guidance as a hard limit.

- Topic: README/specification structure for water-overlay note
  - Decision: Keep the README feature bullet short and link it to a dedicated "About Water Surface" subsection placed after the CLI option table, while mirroring the same warning in `docs/specification.md`.
  - Rationale: The feature list stays scannable, the operational note gets a stable anchor, and the specification keeps the behavioral warning close to the cache/Overpass description without mixing it into the top-level feature summary.

- Topic: Water-overlay subsection placement
  - Decision: Move `About Water Surface` directly under `--water-surface-opacity` and leave the other `About` subsections in place.
  - Rationale: The water warning is the only one that benefits from sitting immediately under its option row. The existing view-center, magnitude-limit, theme, and datetime notes already sit close enough to their respective content and do not need reordering.

- Topic: CLI reference split into docs files
  - Decision: Move the README CLI tables into dedicated Markdown files under `docs/`, and replace the README tables with short links to those files.
  - Rationale: The tables are too wide and too interleaved with prose for maintainable README editing. Separating them by topic keeps the README scannable while preserving the longer option details in focused docs pages.
  - Summary:
    - Added `docs/cli-argument.md`, `docs/cli-observing-location-and-time.md`, `docs/cli-search-objects.md`, `docs/cli-viewpoint-dataset-queries.md`, `docs/cli-sky-and-stars.md`, `docs/cli-overlays.md`, and `docs/cli-general.md`.
