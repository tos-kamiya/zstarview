  - Rationale: Direct Gaussian evaluation removes a temporary stamp allocation and Python slice update for each visible cell while preserving the radius formula and rendering order. Exact RGBA equality on deterministic sparse, typical, and dense workloads supports replacing the production path.
  - Benchmark: `scripts/benchmark_altaz_cloud_renderer.py` renders a 600x600 image from a 90x720 grid, with a 117 degree FOV and five warm repetitions. Active/visible cells were 1,296/1,092, 6,480/5,372, and 22,680/18,764. Reference versus Numba median times were 0.0364/0.0074 s (4.89x), 0.1542/0.0177 s (8.70x), and 0.5269/0.0541 s (9.74x). P95 times were 0.0366/0.0080 s, 0.1561/0.0179 s, and 0.5310/0.0544 s. RGBA outputs were identical in all cases. A fresh Numba cache run took 0.5503 s for the first call, including compilation.

- Topic: Landscape view annotation fade
  - Decision: In Landscape view, fade annotations out over about ten seconds while the pointer is outside the window, on its boundary, or at a screen edge. Moving the pointer back inside restores full opacity immediately; window focus is not part of the condition.
  - Rationale: The edge behavior supports unobstructed full-screen viewing while keeping guide text available when the pointer returns. The fade is limited to annotations so the sky and terrain do not dim with them.
  - Implementation: A GUI timer provides annotation opacity through `RenderHudState`; guide, asterism, label, and HUD annotation rendering applies that opacity. The value participates in the frame cache key.
  - Follow-up: Track host enter/leave events rather than querying global cursor position to detect an outside pointer. Wayland can retain the last in-window position after leave, which made geometry and widget hit-testing unsuitable. Initialize opacity synchronously during mode switching to prevent the initial disappearance.
  - Regression validation: 47 focused fade, display-mode, HUD, and render-cache tests passed, including small and large windows with stale global pointer coordinates. Updated three painter mocks for the opacity API.
  - Validation: Ruff and Python compile checks passed. Tests were not run.
