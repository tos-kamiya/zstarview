- Topic: Nighttime color and ground data
  - Decision: Sum ambient, lunar and ground RGB contributions before an exponential display curve. Use absolute ground normalization (1-exp(-v/20)), sample physical cell centers directly, and retain view-ray extinction. Ground acquisition and raster I/O run entirely inside the existing cloud subprocess, with tile-specific failures contributing zero.
  - Rationale: Scene-relative normalization could brighten rural scenes unexpectedly. Layer-specific center positions are required for satellite parallax. Bounded 512-pixel raster windows limit polar footprint memory use. Actual-distance ray traversal includes the target cell's half-path extinction.
  - Alternatives Considered: Parent-side acquisition adds native lock coordination and can escape the export render deadline. A precomputed coarse geographic field introduces extra resampling. Neither is needed for direct worker sampling. Communication timeouts do not replace the overall subprocess timeout; exhausting that deadline still fails the cloud layer.

  - Rationale: Initial lunar data may arrive after cloud rendering starts, and changes during a worker execution must not clear the required newer refresh. Pending promotion previously rebuilt its key without all appearance inputs.
