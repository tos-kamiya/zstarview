# Session 2026-10-19

Scope: Add Python 3.15 support metadata and validate uv installation.

- Topic: Declare Python 3.15 support
  - Decision: Defer declaring Python 3.15 support. Keep the supported-version
    classifier list through Python 3.14 until the dependency stack can be
    installed and validated on Python 3.15.
  - Rationale: The Python 3.15 install attempt selected h5py 3.16.0, for which
    PyPI did not provide a CPython 3.15 wheel. uv therefore tried a source
    build, which failed because HDF5 development libraries were unavailable.
    This does not establish that h5py itself is incompatible, but it leaves
    the project's 3.15 installation unverified and requires extra system
    build dependencies. Remove the provisional 3.15 classifier until that
    installation path is reliable.
  - Alternatives Considered: Keep the 3.15 classifier and require users to
    install HDF5 build dependencies; defer until prebuilt wheels or a
    validated build setup are available.
