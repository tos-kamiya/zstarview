## Moon outline work

Scope: 月の `outline` 表示に月相を示すアウトラインを追加する。

- Topic: Moon phase in outline mode
  - Decision: 通常の `bright_bodies_mode=outline` では、月の外周円に加えて、既存の太陽方向計算から得た可視半球上の明暗境界を細い弧として描く。ホバー時と `--enlarge-moon` 時は、従来どおり拡大した満ち欠け画像を使う。
  - Rationale: 小さな月マーカーの視認性を保ちつつ、塗りつぶし画像を常時使わずに月相と満ち欠けの向きを伝えられるため。
  - Alternatives Considered: ランドルト環風の単純な C 字形だけにする案は、満月・半月付近の表現力が不足するため、球面上の明暗境界を投影した弧を使う。

- Topic: Hide the dark-side lunar limb
  - Decision: `outline` mode draws only the illuminated half of the Moon's outer limb; the inner terminator arc remains visible. At exact full phase, the full outer circle is retained; at exact new phase, no illuminated outer limb is drawn.
  - Rationale: Avoid presenting the dark side as if it were part of the visible illuminated marker, while keeping the compact phase cue legible.

- Topic: Enlarged Moon crosshair layering
  - Decision: Draw the crosshair before the 5x Moon image so the image is composited above it. Keep the existing order for ordinary-size Moon markers.
  - Rationale: The enlarged lunar image should remain visually unobstructed while the crosshair continues to identify the exact marker center.

- Topic: Duplicate hover crosshair
  - Decision: The hover Moon overlay does not draw its own crosshair; the crosshair from the base planet layer remains beneath the enlarged hover image.
  - Rationale: The base Moon and hover Moon are separate render layers, so drawing both crosshairs produced two nearby cursors when interpolation placed the layers at slightly different positions.
