# Session 2026-05-31

- Scope: Investigate why the tropical cyclone / typhoon overlay stopped appearing in the sky view.
- Topic: Tropical cyclone render fallback at the 400 km boundary
  - Decision: Changed the overlay to fall back to a 1 px vertical line when the 3D cylinder cannot be projected even though the storm center is still within the 400 km visibility range. The outer "far marker" remains only for storms that are actually outside the range.
  - Rationale: The previous code returned early when cylinder construction failed, which created a gap where neither the near cylinder nor the far marker was drawn. That was visible near the range boundary.
  - Validation: `uv run -p .venv/bin/python -m py_compile src/zstarview/render/tropical_cyclones.py tests/test_tropical_cyclones.py`
  - Validation: `uv run -p .venv/bin/python ruff check src/zstarview/render/tropical_cyclones.py tests/test_tropical_cyclones.py`
  - Validation: `uv run -p .venv/bin/python pytest tests/test_tropical_cyclones.py -q`
- Topic: Tropical cyclone base marker for in-range storms
  - Decision: Added a filled downward triangle at the base of the in-range cyclone cylinder, using the same geometry as the far marker but filled in instead of outlined.
  - Rationale: The filled marker gives the viewer a clear surface-contact anchor for the storm body, while keeping the same size language as the out-of-range marker.
  - Validation: `uv run -p .venv/bin/python ruff check src/zstarview/render/tropical_cyclones.py tests/test_tropical_cyclones.py`
  - Validation: `uv run -p .venv/bin/python pytest tests/test_tropical_cyclones.py -q`
- Topic: Tropical cyclone base marker anchoring
  - Decision: Re-anchored the filled triangle so its tip sits exactly on the cyclone base contact point instead of centering the triangle on that point.
  - Rationale: The earlier centered placement left the tip offset from the actual contact point, which made the marker easy to miss when the label and water dots were dense.
  - Validation: `uv run -p .venv/bin/python ruff check src/zstarview/render/tropical_cyclones.py tests/test_tropical_cyclones.py`
  - Validation: `uv run -p .venv/bin/python pytest tests/test_tropical_cyclones.py -q`
- Summary: Fixed the missing-typhoon edge case by making the in-range fallback a thin line instead of an invisible gap or an out-of-range marker.
