## Decision Log
- Topic: Square Window one-shot revert
  - Decision: Reverted `Square Window` from a persistent toggle back to a one-shot menu action that immediately resizes the client area to a square using the shorter side.
  - Rationale: The toggle-based correction conflicted with external window reflow tools, so removing the retained square-state and the resize-time correction path restores the simpler interaction model.
  - Alternatives Considered: Keeping the toggle but disabling the pending correction logic. That would leave a misleading checked state in the menu without the original behavior the user wanted.
