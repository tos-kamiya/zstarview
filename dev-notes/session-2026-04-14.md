- Topic: Himawari far-miss fallback split
  - Decision: Split Himawari fallback behavior so observer-facing render tiles may treat far missing regions as clear sky, while equator-band warm-threshold tiles fall back to the last valid threshold instead of clear-sky filling.
  - Rationale: The two tile groups serve different purposes. Rendering benefits from visual continuity, but warm-threshold estimation should prefer a stable prior value over inventing clear-sky samples.
