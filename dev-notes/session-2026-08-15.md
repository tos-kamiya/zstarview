# Session 2026-08-15

Scope: Adjust scintillation altitude sampling and display opacity.

- Topic: Scintillation altitude distribution
  - Decision: Sample altitude as `10 + 80 * x**2.5`, where `x` is a uniform random value, and sample azimuth uniformly from 0 to 360 degrees. Discard directions outside the current view.
  - Rationale: Concentrate selections toward lower altitudes without using a lookup table or spherical-area weighting.

- Topic: Scintillation opacity
  - Decision: Linearly vary opacity from 0.5 at 10 degrees to 0 at 90 degrees; use 0.5 from 0 to 10 degrees.
  - Rationale: Reduce the effect at high altitude while retaining a visible low-altitude effect.

- Topic: Scintillation target count
  - Decision: Expose the per-update target count as `--scintillation-count` in the normal GUI CLI, with a default of 10. Do not expose it in Atlas or `zstarview-export-image`.
  - Rationale: Allow visual tuning while keeping the non-scenic entry points protected from the display-only effect.

- Topic: Startup dialog controls
  - Decision: Add scintillation count under `Celestial`, and Meteor trails opacity and maximum candidates under `Atmosphere`. Hide only the scintillation count from Atlas; retain Atlas's existing Meteor trails menu.
  - Rationale: Keep star-specific controls with celestial settings and transient overlay controls with atmosphere settings while preserving the existing Atlas Meteor behavior.
