# Session 2026-05-13

Scope: Investigate and fix startup freezes caused by synchronous fetches during application launch.

- Topic: Startup launch path
  - Decision: Move launch-time location resolution, ephemeris verification, and startup search into a background worker started after the window is shown.
  - Rationale: The previous flow ran network-heavy work before the Qt event loop became available, which could leave the window unresponsive long enough for the OS "not responding" dialog to appear.
  - Verification: `uv run -p .venv/bin/python ruff check src/zstarview/gui/viewer.py tests/test_viewer_startup_errors.py`
  - Verification: `uv run -p .venv/bin/python pytest tests/test_viewer_startup_errors.py tests/test_startup_log.py`
