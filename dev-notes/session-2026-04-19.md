# Session 2026-04-19

- Scope: search CLI/refactor follow-up

- Topic: `--list` scope clarification
  - Decision: `--list` is supported only by `zstarview-export-image`; GUI CLI rejects it with an error.
  - Rationale: `--list` is an exploration mode for headless search resolution. In the GUI, ambiguous search should be handled through the interactive dialog instead of a separate list-only mode.

- Topic: Startup search splash stall
  - Decision: Defer GUI startup search until after the initial sky-data-loaded signal closes the splash screen.
  - Rationale: Running search resolution too early can delay or interfere with the initial-data signal path; delaying it avoids holding the splash open and keeps startup responsive.

- Topic: Export-image search overlay parity
  - Decision: Clamp search-driven view centers to the GUI floor altitude and render the selected search target's marker/label into export-image output.
  - Rationale: `zstarview-export-image` should match GUI behavior for low-altitude jumps while still showing the resolved target on the exported image.

- Topic: Design doc finalized
  - Decision: Treat the shared search resolver split in `docs/design.md` as the decided design.
  - Rationale: The shared search package and export-image overlay path are now in place, so the design document should describe the current intended architecture rather than a provisional plan.

- Topic: CLI opacity short options
  - Decision: Add `-d` for `--terrain-horizon-opacity`, `-u` for `--urban-outline-opacity`, and `-e` for `--earth-guide-opacity`.
  - Rationale: These are frequently adjusted overlay controls, and short aliases reduce command-line friction without changing defaults or behavior.
  - Validation: Added parser tests for each short option; `compileall` passed in this environment.

- Topic: Version bump
  - Decision: Bump the package version from `1.20.1` to `1.20.2`.
  - Rationale: This is a patch-level release for the CLI and documentation updates.
