# Session 2026-08-08

Scope: Reduce the Matsue Station timelapse video size for GitHub README
attachment.

- Topic: Timelapse MP4 generation command
  - Command:
    ```text
    ffmpeg \
      -pattern_type glob \
      -framerate 10 \
      -i '/home/toshihiro/.cache/zstarview/debug/aircraft-ready5/*.png' \
      -vf 'scale=512:512' \
      -c:v libx264 \
      -preset slow \
      -crf 29 \
      -tune animation \
      -pix_fmt yuv420p \
      -movflags +faststart \
      -an \
      /home/toshihiro/.cache/zstarview/debug/timelapse-matsueeki-small.mp4
    ```
  - Result: The generated MP4 was approximately 4.9 MB and suitable for
    GitHub's video attachment limit.
