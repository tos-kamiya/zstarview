# Session 2026-06-24 — Cloud stripe count now absolute

## Scope
Change `--cloud-stripe` `COUNT` semantics from "density relative to 600x600 star surface" to an absolute stripe count that does not scale with window size.

## Decision Log

- Topic: Cloud stripe `COUNT` scaling behavior
  - Decision: `COUNT` is now interpreted as the absolute number of stripes/cells across the disc. It is no longer multiplied by the render surface size / 600.
  - Rationale: The user asked that a value like `jellybean,20` keep 20 divisions even when the window is enlarged, so stripe spacing grows with the window instead of density staying constant.
  - Alternatives Considered: Adding a new option (e.g. `jellybean,20,absolute`). Rejected because the desired behavior is simpler and matches the literal meaning of the count parameter.

## Implementation Notes

- `src/zstarview/gui/composite.py`:
  - `_scaled_cloud_target_stripes()` now returns `max(1, int(target_stripes))` unchanged, ignoring the reference size parameters (kept for API compatibility).
  - For `jellybean` mode, grid spacing `delta` is now computed from the actual output diameter (`min(w, h)`) divided by `target_stripes`, instead of the star-layer reference size. This makes the number of jellybean chains constant across window sizes.
  - `width`/`alpha` modes already used `_scaled_cloud_target_stripes()` to derive `period = diameter / stripes`, so with the helper returning the absolute count, they naturally keep the same stripe count on larger windows (period grows proportionally).

- `src/zstarview/cli/args.py`: Updated `--cloud-stripe` help text to say count is absolute and not scaled.

- `docs/cli-overlays.md` / `docs/cli-overlays-ja_JP.md`: Updated user-facing descriptions of `COUNT` to match the new behavior.

- `tests/clouddisc/test_cloud_hatch.py`:
  - Renamed `test_scaled_cloud_target_stripes_tracks_buffer_size` to `test_scaled_cloud_target_stripes_is_absolute` and adjusted assertions.
  - Renamed `test_variable_width_cloud_stripes_use_star_surface_density` to `test_variable_width_cloud_stripes_keep_same_count_across_sizes`, removed the `density_reference_size` test path, and compared 800x800 vs 1200x1200 outputs to verify equal stripe counts (sizes chosen to stay above the minimum period clamp).



- Topic: Default cloud options changed to jellybean,24 / opacity 0.05
  - Decision: Changed the default `--cloud-stripe` to `jellybean,24,1.0` and `--cloud-opacity` to `0.05` for all entry points (`zstarview`, `zstarview-gui`, `zstarview-export-image`).
  - Rationale: User requested these defaults. The GUI launch profile derives from `parse_args([])`, so updating the CLI argument defaults automatically propagates to the GUI startup dialog.
  - Files changed: `src/zstarview/cli/args.py`, `docs/cli-overlays.md`, `docs/cli-overlays-ja_JP.md`.


- Topic: Subtle jellybean outline
  - Decision: Added a faint outline pass behind each jellybean circle/chain before drawing the main shape.
  - Implementation: In `_render_jellybean_cloud_rgba_from_altaz_grid`, draw each shape once with `diam + 3.0` px width and 20% of the main alpha, then draw the normal shape on top. Because the same RoundCap geometry is used, the halo blends naturally around the round line ends.
  - Rationale: User wanted a barely-there contour around clouds. Since the jellybean style renders as round-cap line segments, a true polygon outline is not available; a slightly thicker low-alpha stroke is the natural equivalent.


- Topic: Updated design/spec docs for cloud stripe changes
  - Decision: Updated `docs/design/rendering-pipeline.md` and `docs/specification.md` to reflect the new jellybean default, absolute `COUNT` semantics, and subtle outline pass.
  - Details:
    - `docs/specification.md`: Added section `6.8.1 雲ストライプ` describing `--cloud-stripe`, the three modes, default `jellybean,24,1.0`, and cloud opacity default `0.05`.
    - `docs/design/rendering-pipeline.md`: Replaced outdated MVP circle description with the three stripe modes, moved the detailed jellybean algorithm into `4.2a 雲ストライプ描画モード`, and documented the low-alpha outline pass.
