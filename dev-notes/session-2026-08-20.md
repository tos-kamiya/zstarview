# Session 2026-08-20

- Scope: zstarview の恒星カタログのデータ元と更新状況の調査

- Topic: 同梱恒星カタログの構成確認
  - Decision: 現行ランタイムは `src/zstarview/data/stars/` の分割 CSV を読み込み、外部から恒星データを実行時取得しない。CSV は Hipparcos I/311（`hip2.dat.gz`）を主データとし、Tycho-2 I/259 を暗い星の補完として統合したもの。
  - Rationale: `catalog.py`、生成スクリプト、生成ガイド、CSV の `SourceCatalog` 列、および 2026-07-31 の `feat: refresh bundled catalogs` コミットを確認した。現行 CSV の集計は Hipparcos 111,734 行、Tycho-2 423,382 行、合計 535,116 行（ヘッダー除く）。
  - Alternatives Considered: 旧 Hipparcos I/239 (`hip_main.dat.zip`) は同梱されているが、現行生成の既定入力ではなく、互換入力として保持されている。

- Topic: 公式データ元の更新状況
  - Decision: Hipparcos I/311 は CDS の「Hipparcos, the New Reduction (van Leeuwen, 2007)」、Tycho-2 I/259 は CDS の「The Tycho-2 Catalogue (Hog et al., 2000)」であり、これらの同一カタログの後続版は確認できなかった。より新しい主要候補は Gaia DR3（2022-06-13 公開）で、Gaia DR4 は ESA が 2026 年中・mid-2026 以降の予定として案内している。
  - Rationale: CDS の I/311・I/259 ReadMe と ESA Gaia の公式 DR3/DR4 ページを 2026-08-20 に照合した。したがって「現行カタログが未更新」という意味では、Hipparcos/Tycho-2 の固定版を使用している限り正しい。ただし、最新の恒星位置・固有運動・測光を採用する観点では Gaia DR3 への更新余地がある。

- Summary: 調査のみ。実装・同梱データの変更は行っていない。

- Topic: Gaia DR3 置換時の互換性
  - Decision: Gaia DR3 はデータ品質・収録数の面では有力な後継だが、現行カタログの上位互換ではない。`source_id` は HIP/TYC と異なる Gaia 固有 ID であり、星名検索・アステリズム定義・既存参照を維持するにはクロスマッチ層が必要。
  - Rationale: 現行コードは `SourceId` を文字列として保持し、アステリズム定義は `HIP...` を直接参照する。Gaia DR3 は `G`/`BP`/`RP` 測光で、現行の `Vmag`/`B-V` と体系が異なる。Gaia 公式には Hipparcos-2/Tycho-2 とのクロスマッチが提供されているため、段階移行は可能。
