# Session 2026-03-31

- Scope: Adjust cloud stripe visibility after the new minimum-width threshold hid expected cloud regions.

- Topic: Revert the 2px minimum stripe visibility threshold
  - Decision: Removed the hard `2.0px` minimum-width gate so thin cloud stripes are allowed to render again.
  - Rationale: The threshold improved legibility but also suppressed cloud structure in regions where clouds should still be visible, which is a larger regression than the thin-band noise it avoided.

- Topic: Remove the extra cloud opacity scale and lower the CLI default
  - Decision: Removed the compositor-side `0.7` cloud opacity multiplier and changed the CLI `--cloud-opacity` default from `0.15` to `0.1`.
  - Rationale: Cloud opacity should now mean exactly what the CLI says, and the previous combination of `0.15 * 0.7` was both indirect and visually stronger than desired for the current stripe rendering.

- Topic: Lower the cloud amount normalization floor percentile
  - Decision: Changed the lower percentile used for `cloud_amount_field` normalization from `20` to `8`.
  - Rationale: Sparse cloud regions had become too hard to see after the width-based stripe rewrite. Lowering the normalization floor keeps more low-cloud signal visible without changing the rest of the stripe renderer.
