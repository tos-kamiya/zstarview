# Session 2026-07-06

Scope: Explore sky-aware cloud tinting for night and twilight rendering.

- Topic: Cloud tint preview
  - Decision: Add a standalone HTML swatch under `dev-samples/` instead of changing runtime rendering immediately.
  - Rationale: The color policy is visual and subjective. A static preview lets us compare current white clouds with a sky-aware HSV tint before touching the renderer.
  - Alternatives Considered: Directly changing `compose_cloud_over_sky()` was deferred because twilight and sunset behavior needs visual validation first.

- Topic: Night cloud tint policy
  - Decision: Use a simple sun-altitude based cloud tint: white through twilight, smoothly transitioning to blue-gray at night.
  - Rationale: The HSV sky-aware preview showed little practical variation except at night once white mixing was applied. A sun-altitude rule addresses intrusive white clouds at night while avoiding odd blue clouds in red sunset skies.
  - Alternatives Considered: Sampling local sky-disc color for each cloud mark was rejected for now because it adds complexity and risks over-colored sunset clouds.

- Topic: Night cloud tint visibility
  - Decision: Raise the night cloud tint from `(154, 167, 196)` to `(184, 196, 224)`.
  - Rationale: The first blue-gray tint reduced nighttime glare but made clouds harder to see. The brighter tint keeps the color away from pure white while restoring visibility.
