  - Topic: Document tropical cyclone overlay behavior
    - Decision: Added specification and design notes for a public ArcGIS-based tropical cyclone feed, including current position, forecast position, wind polygon layers, ADVDATE-based refresh, 90-minute lightweight update checks, and 3-hour cache expiry.
    - Rationale: The feed is useful enough to document now, but the exact rendering style is still open, so the docs capture data semantics and cache/update policy without overcommitting to visual design.
  - Topic: Inverted danger-surface visualization
    - Decision: Documented a stepped inverted-terrain presentation as an allowed rendering metaphor, with stronger wind bands placed closer to the ground and weaker bands lifted higher.
    - Rationale: The metaphor preserves the horizontal footprint of the storm while making the strongest wind field read as the lowest, most dangerous layer. The shape can stay circular or polygonal; it does not need a square base.
  - Topic: Tropical cyclone overlay implementation
