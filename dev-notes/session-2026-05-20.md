- Topic: export-image defensive `getattr()` cleanup
  - Decision: remove the remaining clearly redundant `getattr()` calls
    in `src/zstarview/cli/export_image.py` and switch them to direct
    attribute access for CLI args, resolved locations, prepared catalogs,

- Topic: internal GUI state `getattr()` cleanup
  - Decision: remove compatibility-oriented `getattr()` calls from
    `src/zstarview/gui/window.py` and `src/zstarview/gui/window_updates.py`

    state that already exists in production.
  - Rationale: these reads were masking the real contracts between the
    window shell, render/update mixins, and `SkyWindowState`. Direct

    inputs such as Qt event objects, widget hooks, controller feature
