Session: 2026-04-12 cloud distribution threshold transition

- Topic: Cloud shell distribution transition
  - Decision: Replace the fixed 3 km / 5 km / 7 km blend with a scene-cloud-amount driven transition. Use middle-only weighting below 0.25, then smoothly interpolate to the default 0.2 / 0.6 / 0.2 mix by 0.65.
  - Rationale: Low cloud scenes look more natural when concentrated near the middle layer, while stronger cloud scenes still benefit from the existing 3-layer spread. A smooth interpolation avoids hard visual jumps at the threshold.
  - Validation: Ran `uv run -p .venv/bin/python pytest tests/clouddisc`; 46 tests passed.

- Topic: Version bump
  - Decision: Bump the application version from `1.9.7` to `1.9.8`.

- Topic: Window repaint flicker
