# Session 2026-05-17

- Scope: Inspect how sea-surface `.tiff` tiles are stored in memory.
- Summary: Sea-mask GeoTIFFs are not retained as full raster payloads in memory.
  The code opens each tile with `rasterio`, reads only the needed window or
  samples, converts the result into boolean flags or `WaterOverlayPoint`
  tuples, and caches only those derived point sets plus stats in controller
  state.

  points whose surrounding tiles are all `.tif` across 125m/250m/500m roots.
  Verified the current dataset yields 5 shared intersections with `pytest` and
  `ruff check`.

- Summary: Added `dev-samples/debug_water_controller_probe.py` to show the

  6-8.98 km to 500m. The 125m/250m tiles are 0 at this location while 500m
  tiles are 1, which explains the 0-dot GUI result.
