- Topic: Cloud source sampler cache
  - Decision: Cache the brightness-temperature sampler on `CloudSourceData` and reuse it across repeated renders for the same fetched cloud source.
  - Rationale: During Alt/Az interaction, the source satellite data often stays the same while only the camera changes. Reusing the sampler avoids repeated `build_bt_sampler()` setup without changing any user-visible rendering behavior.
  - Alternatives Considered: Caching full rendered images or projection grids would affect behavior and cache invalidation more broadly; sampler reuse is narrower and lower risk.
