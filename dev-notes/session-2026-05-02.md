# 2026-05-02

Scope: Investigate GUI search behavior when `-A/-Z` are supplied on startup.

- Topic: Search jump vs. fixed CLI view center
  - Decision: The current implementation keeps the CLI-specified view center when `-A` or `-Z` are explicitly provided, even after a place search result is selected.
  - Rationale: `SkyWindow._jump_to_search_target()` preserves the base `view_center` whenever the explicit-altitude/azimuth flags are set. The visible target highlight is temporary and lasts about 3 seconds, so the UI can look like it "returns" after the highlight fades.
  - Alternatives Considered: None yet. If the intended behavior is for place search to override CLI view-center arguments, that would require a code change in the jump logic.
- Summary
  - Implemented per-search control for keeping CLI Alt/Az in both search dialogs.
  - Verified with `pytest tests/test_place_search_dialog.py tests/test_window_render_sync.py` and targeted `ruff check` on the edited files.
